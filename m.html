The Problem

How It Works

From agent tap to settled ledger

01

Customer presents network & amount

The agent selects the customer's preferred network on the MPoint terminal. M-Pesa, Airtel Money, Equitel, or bank — all in one menu.

02

MPoint routes to the correct API

The UnifiedAgent core resolves the network, validates float availability, and initiates a Daraja B2C, Airtel, or bank transfer request with an idempotency key.

03

Outbox commits the transaction

The ledger writes the transaction in the same DB transaction as the outbox event — guaranteeing settlement even if the downstream API call fails or times out.

04

Agent float updates in real time

Balances across all networks refresh instantly. End-of-day reconciliation is automatic — no manual tallying, no disputes.
